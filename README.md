# SafeMeter - UI/UX Design Project

## 📖 Project Overview

SafeMeter is a mobile application concept designed to improve safety and fare transparency for Sri Lankan tuk-tuk passengers. The app allows users to estimate ride fares, track trips in real time, share live locations with trusted contacts, and access emergency assistance through an SOS feature. The project focuses on creating a simple, accessible, and trustworthy transportation experience.

## 🎯 Project Goal

The goal of this project was to:

- Create an intuitive mobile experience for tuk-tuk passengers in Sri Lanka
- Solve fare uncertainty and passenger safety concerns through thoughtful design
- Deliver a seamless and accessible user experience for everyday transportation

## 📊 User Research Summary

### Target Users
Tuk-tuk passengers in Sri Lanka

### Key Findings
- Passengers often face fare uncertainty before rides
- Many users have safety concerns when traveling alone
- Users prefer a simple way to share trip details with family or friends
- Emergency assistance should be accessible within one tap

### Design Improvements
- Added fare breakdown visibility
- Included trip-sharing functionality
- Designed a dedicated emergency SOS workflow
- Simplified navigation for faster task completion
